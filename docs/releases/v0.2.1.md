## FM27 Trainer 0.2.1 — Windows live-tested

**Windows is no longer read-only.** Everything was checked live on the Steam build of November 2026 (26340721):
reading club, squad, date and training calendar; budgets, morale, injuries, training days and selling, each with
undo. The app connects to `fm.exe` as before, nothing to install.

### Fixed
- **Screen reading (Tactical Effectiveness Breakdown).** The empty part of each pie is near-white in FM27's UI, which the
  reader took for "full"; highlighted rows hid their gauges, and the Player Buy-In bar was missed because Windows OCR reads
  "Buy-In" as "Buy-ln". All 17 gauges and 4 bars now read as whole segments (4 of 10 = 40). Every capture is saved
  as `last-capture.png` in the app's data folder (`%APPDATA%\FM27 Trainer` on Windows) so a wrong reading can be replayed
  with `fm27-trainer analyze <png> --ocr`.
- **Selling** now adds the fee to your transfer budget as well as your balance (undo takes both back).
- **Finding classes in `game_plugin.dll`.** The DLL is packed and its sections are not named `.data`/`.rdata`, so the
  RTTI lookup found nothing on Windows and selling refused to run. It now scans every data section.
- Heap scans were some 40 times slower in a debug build; the agent crate is now optimised in `cargo run` too.
- A test capture (`FM27_SNAPSHOT`) never writes training into FM any more.

### Notes
- After an FM patch the app is read-only again until the new build has been checked; you can allow changes in Settings.
- The macOS DMG for this version is built on a Mac with `./release.sh`; the Windows zip comes from GitHub Actions.
