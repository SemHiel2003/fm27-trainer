## FM27 Trainer 0.2.3 — Buy players, keep tactical understanding at 100 %

### New
- **Buy players.** The Sell page is now *Transfers* with a Buy tab: search a club, pick a player from its first
  team (value, wage and contract end shown), set the fee and wage, check, and he moves into your first team. You
  pay the fee from your balance and transfer budget, the selling club receives it. Same safety as selling:
  check first, undo until you save in FM. Player-coaches and loaned players are not supported yet.
- **Keep at 100 %.** FM lets tactical understanding drop again every game week (four game months after a
  maximise, every player was back at 76 %). The Squad page now has a switch that keeps it at 100 % while the app
  is open: every 20 seconds, during the normal connection check, the app puts back whatever has dropped and writes
  nothing when nothing changed. Each correction is listed in the Training page's activity log.

- **Rules.** The Club page gets the two switches FM's in-game editor has for your manager: *register players
  anytime* and *change squad numbers anytime*. They set the same flags the editor sets; check the effect on the
  competition's registration screen in FM.

### Fixed
- **"Training calendar not found".** The app looked for FM's calendar among the first 20,000 places in memory that
  point to your team and stopped there, and a single unusual day (an empty slot, a flag FM sets on a day) made it
  reject the whole calendar. It now searches all of memory and accepts such weeks; a day it does not recognise is
  left exactly as FM has it. If the calendar still is not found, the message says what was seen, so it can be
  reported.
- **Gauges read wrong with larger text in FM.** With a bigger text size (or tighter rows) the reading of one gauge
  could pick up part of the gauge above or below it, so a ring under half full could come out as 70. Each gauge is
  now measured on its own, only pixels in the gauge's own fill colour count, and a reading whose colour does not
  fit (FM paints low values orange, middle yellow, high green) is flagged after reading so you can check it.
- **Game Pass / Xbox app.** FM27 from the Xbox app (0.9.2409.0) is now recognised: date, staff and club list are
  known, and the class search no longer skips the sections where that build keeps them. It uses the same
  checks before every change as Steam; it has not been live-tested by us on Game Pass yet. FM on an Xbox console
  cannot be read: the app needs FM running on the same PC.
- **Settings → Open app folder** opens the folder with the last screenshot (`last-breakdown.png`): send it along
  when a gauge is read wrong.
