## FM27 Trainer 0.2.5 — Training calendar found again

### Fixed
- **"Training calendar not found" on the Training page.** In some saves FM keeps a number in a part of each
  training day that was empty in every save the app had been measured on. The app took that for a sign that it
  was looking at the wrong data and rejected the whole calendar, so planning and applying training failed. It no
  longer looks at that part; it never reads or changes it. Confirmed on the Windows save of the user who reported
  it. Thanks to @zimboking for the fix (#4, reported in #3).

### Under the hood
- The release build now runs the tests before it builds the Windows version.
